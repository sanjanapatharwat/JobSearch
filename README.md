# Job Search App

A responsive web application for searching and filtering job listings based on various criteria such as job title, location, remote/on-site status, salary, experience level, and more.

# Overview

This project provides a simple and user-friendly interface for job seekers to browse current openings using live job data from a public job API. It helps users narrow down jobs quickly using filters and view key details such as company, location, posting date, salary, and application link.

## Features

- Search jobs by title or keyword
- Search by location or country
- Filter by:
  - Job type
  - Remote / On-site
  - Posted date
  - Salary visibility
  - Experience level
  - Minimum salary
  - Company name
  - Direct-apply jobs only
- View job cards with:
  - Company name
  - Job title
  - Location
  - Employment type
  - Salary information
  - Description preview
  - Apply links
- Responsive layout for desktop and mobile browsing
- Clear filters option to reset the search

## Tech Stack

- HTML5
- CSS3
- JavaScript
- RapidAPI (JSearch API)
